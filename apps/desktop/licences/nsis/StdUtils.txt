Mr. Streamer's Windows setup program carries StdUtils.dll, unmodified, and so does the uninstaller it leaves in the app's folder. It is a separate file that NSIS unpacks and loads when either runs. The Microsoft Store package and the Mac and Linux builds don't contain it.
