Microsoft's Direct3D compiler files, in the Windows builds

Electron {electron}'s Windows build carries d3dcompiler_47.dll from Microsoft beside its executable; dxil.dll is no longer included. Mr. Streamer ships it unchanged in the Windows setup program and in the Microsoft Store package. The Mac and Linux builds don't contain it.

d3dcompiler_47.dll, version {D3DCOMPILER_VERSION}
Direct3D HLSL Compiler for Redistribution
© Microsoft Corporation. All rights reserved.

Microsoft owns this file and licenses it under its own terms, not as open source. Mr. Streamer has no source for it and can't offer it under its own licence. Chromium's graphics code loads it to compile shaders.

Chromium's build copies it from Microsoft's Windows SDK. Microsoft lists it among the SDK's files that may be redistributed, under the SDK's licence terms:
https://learn.microsoft.com/en-us/legal/windows-sdk/redist
https://learn.microsoft.com/en-us/legal/windows-sdk/license

This project hasn't confirmed which Microsoft terms Electron's builders redistribute it under.

dxcompiler.dll, beside it, is another case: it is built from the open-source DirectX Shader Compiler, and Chromium's credits hold its licence.
