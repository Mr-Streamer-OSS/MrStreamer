Stable release on GitHub. What changed.

On Windows, the Microsoft Store installs Mr. Streamer and keeps it updated. Every other installer comes from GitHub Releases, and the app then checks for updates on its own.

macOS 13 or later, Apple silicon
Download the DMG on GitHub Releases Open it and drag Mr. Streamer to Applications.
Windows 11, 64-bit
Microsoft Store Download the setup .exe on GitHub Releases The .exe installs for your user without administrator rights. It isn't signed yet, so SmartScreen may warn. Choose More info, then Run anyway.
Linux, 64-bit
Download the AppImage on GitHub Releases Download the .deb on GitHub Releases The AppImage needs FUSE 2, which is libfuse2t64 on Ubuntu. The .deb is for Ubuntu and Debian.
