# Android subtitles

Android subtitle logic is in `apps/android/src/subtitles/`: `model.ts` supplies the designer's state/actions, `service.ts` asks SubDL for an exact movie or episode, and `runtime.ts` binds exact provider versions and downloaded copies to retained cues. The key uses the sealed Android secret adapter. `apps/android/src/subtitles/runtime.ts` resolves streamed episodes from Library's loaded details while the signed-in reader still matches, with the catalogue's exact episode-file mapping as a fallback. Media3 merges an in-memory text sidecar into the existing owner; Kotlin bounds ZIP extraction, converts cue clocks, and preserves position and pause while replacing text. Retained-data deletion and key removal do not invalidate native bytes already being read. File tracks, Off and the sidecar use the same reported track selection. Watch's UI is in `apps/android/src/subtitles/sheets.tsx`: the downloaded row, Find online (titles only) and Adjust timing under the Subtitles sheet's file tracks in `apps/android/src/player/media-controls.tsx`, the Online subtitles, Adjust timing and Frame rate sheets, and the key and failure dialogs, with copy in `apps/android/src/subtitles/copy.ts`. Adjust timing raises the native cue through `inset()` while it shows and restores 0.08 on close. `apps/android/src/subtitles/settings-section.tsx` renders the Settings group (key, text size, refused writes through Settings' snackbar) and stays unmounted pending the Settings ownership handoff. Focused contracts live in `apps/android/test/subtitles-runtime.test.ts`, `apps/android/test/subtitles.test.ts`, `apps/android/test/subtitles-service.test.ts`, `apps/android/test/subtitles-watch.test.ts` and the player module's Kotlin tests. Device proof remains required for cue drawing, timing against video, rotation, PiP, TalkBack/D-pad and a real offline route; JVM selection and source wiring do not establish those outcomes.
