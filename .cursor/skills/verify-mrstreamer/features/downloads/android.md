# Android bulk downloads and offline Next

## Android 0.1.0 bulk downloads and checked offline Next

Android Library offers **Download remaining** for the selected season and **Review series download** for the series. The review keeps its version and counts fixed, includes Specials in the series order, and separates new additions, already saved or queued copies, failures and stopped work. Native admission rechecks the ledger and sign-in for every addition; JavaScript rechecks the selected version between admissions. Cancel remaining, leaving the series and changing versions stop unqueued work; accepted additions settle. Opening Downloads over Details keeps the run alive. Missing files can be replaced immediately; changed files ask first, and a playing copy is refused. Bulk replacement replaces missing files only. Queue pause and order persist in the native ledger; Android scheduling and force stop can defer continuation.

At a downloaded episode's end, Watch reads only the immediate next episode's checked copy. A ready copy shows **Downloaded**, the retained subtitle language when available, and **Plays in N** while the existing countdown runs. Cancel leaves manual **Play next**. Still downloading, not on this device and read failures offer **Play again** and **Downloads**; missing or changed files offer **Replace** with the same confirmation rules. No action streams or skips a gap. Subtitle records saved during file playback bind to the transfer id, checked file path, size and modification time. The same intact file restores the subtitle and timing; a new transfer, changed metadata, failed native file check or any unbound record (including a legacy record or one last saved while streaming) cannot restore it offline. Legacy records remain readable for streaming. Downloads made before series order was stored cannot continue offline until a bulk review for that series backfills their order while provider details are available. This metadata binding does not detect external tampering that preserves both size and modification time.
