## Archived 0.0.15 compatibility

Run `node apps/desktop/test/e2e/analytics-downgrade.ts` from the checkout root, and repeat with `v0.0.18` as its positional argument for the summary-aware prior release. It reads the selected tag through Git and executes its actual archived public loader/owner with this checkout's dependencies. The printed `.local/verification/analytics-downgrade-*` directory retains `proof.json` with the exact tag revision, source hashes, consent/identity/legacy-event preservation, unsupported-summary/version removal on an old-build write, opt-out/re-enable and no revival. A copied schema is insufficient proof.

This helper uses local stores and an injected transport. Its crash is an atomic-file snapshot. It does not exercise an installed old binary, native upgrade or process kill. No-write return recovery and real HTTP delivery need their separate recorded proofs; exact-candidate native acceptance remains on the release card.
